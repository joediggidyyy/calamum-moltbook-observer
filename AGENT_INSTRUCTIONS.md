# Calamum Observer - Agent Instructions

> **Classification**: Project-Level Directives  
> **Scope**: `projects/calamum-moltbook-observer/`  
> **Inheritance**: Extends `CodeSentinel-1` root instructions

## 1. File Locality & Hygiene (CRITICAL)

**Directives**:
1.  **Project Encapsulation**: ALL data, logs, and artifacts generated by this project MUST reside within `projects/calamum-moltbook-observer/`.
    -   **Forbidden**: Do NOT write to `logs/data/calamum/` in the repo root.
    -   **Forbidden**: Do NOT write to `logs/calamum/` in the repo root.
2.  **Data Storage**:
    -   Raw/Source data: `projects/calamum-moltbook-observer/local_untracked/analysis/data_archive/`
    -   Analysis/Training artifacts: `projects/calamum-moltbook-observer/local_untracked/analysis/`
    -   Runtime logs: `projects/calamum-moltbook-observer/logs/`
3.  **Path Resolution**:
    -   Always use `pathlib.Path` relative to `__file__` or find the project root via `PROJECT_MANIFEST.json`.
    -   Never assume the CWD is the project root.

## 2. Training Data Protocols

**Directives**:
1.  **Job 0012 Compliance**: Training operations defined in Job 12 must use the artifacts in `local_untracked/analysis/`.
2.  **Manifest Usage**: All training runs must be triggered via a `dataset_manifest.json` generated by `dataset_builder.py`.
3.  **Reporting**: Training results must be logged to `planning/` or `jobs/` as defined in the associated Job definition.

## 3. Operational Health

**Directives**:
1.  **Pre-Flight**: Before significant changes, run `tools/audit_repo_health.py`.
2.  **Verify Integrity**: Ensure `src/requirements.txt` matches the import usage in `src/`.
