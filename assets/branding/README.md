# Calamum branding assets

Drop the provided branding images into this folder.

Expected filenames (recommended):
- `calamum_banner_thumb.png`  (small thumbnail for header)
- `calamum_panel_badge.png`   (larger badge/art for bottom of Control Deck)

The UI will fall back to a simple icon if these files are missing.

Optional overrides (absolute or repo-relative paths):
- `CALAMUM_BRAND_THUMB_PATH`
- `CALAMUM_BRAND_PANEL_PATH`
